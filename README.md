## 🧭 About Me

I enjoy building systems where **AI is one component of a larger engineered pipeline rather than the entire product**.

My work spans **RAG systems, LLM-powered products, local model inference, machine-learning pipelines, backend APIs, constrained optimization, full-stack applications, and compiler tooling**. I like taking projects beyond a model or prototype — designing the architecture, connecting the components, handling constraints and failure cases, testing the system, and turning the idea into usable software.

Recent work has included a **neuro-symbolic floor-plan generator combining retrieval with constraint solving**, an **AI founder pressure simulator powered by NVIDIA Nemotron**, a **Fortran–C ABI compatibility validator built around LLVM/Clang and Flang**, and **local LoRA-adapted LLM systems for legal reasoning**.

I care about **architecture, correctness, evaluation, and building technically interesting software that solves a real problem**.
